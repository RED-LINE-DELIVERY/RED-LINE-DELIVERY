REDLINE DELIVERY WEBSITE

1. Extract this ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the Redline-Delivery folder.
4. Open index.html.
5. To preview, right-click index.html and choose "Open with Live Server" (if the Live Server extension is installed), or open index.html directly in your browser.

Note: This is a visual tracking demonstration only. It does not connect to a real courier or provide live parcel updates.
